It’s fine to include some AI-generated content as long as a) you’re clear about it and b) it’s not your whole portfolio.

The AI used in these projects would go above small-scale tools like GitHub Copilot - 
in this context, AI-driven coding means that you are iteratively guiding the AI as it designs experiments, 
writes whole scripts/big chunks of code, etc.

These days, many companies encourage some amount of vibe coding because of the potential efficiency. 
It can therefore be beneficial to demonstrate that you know how to use a few AI/LLM tools, 
particularly in ways that help get a project done. 
This doesn’t mean that you HAVE to include AI in your portfolio - it just means that if you want to, there are ways to do it appropriately.

For these projects, consider addressing:
-  If AI is doing the coding/design, what skills are you practicing?
-  How can you assess whether the AI is doing a good job?
