# Example Portfolio

This is an example portfolio for bioinformatics undergraduates. **It is meant purely as a starting point** - feel free to organize your portfolio however you like.

No AI was used to generate the portfolio.

## Key Portfolio Elements
-  **Be clear:** stay organized, make everything easy to understand and follow.
-  **Start small, build big:** for beginners, something is better than nothing. As you advance, start creating bigger projects that incorporate more complexity.
-  **A few strong projects are better than dozens of simple ones.** Notice how the simpler projects here are grouped into categories called 'Statistics' and 'Machine Learning' - still included, but not cluttering up the main folder.

## Include README files

In GitHub, README.md files are automatically loaded as a text file in any given folder. They are therefore used to provide context. 
For each project, I recommend including:
-  The purpose of the folder
-  Any general info needed to understand the folder (what’s included, how subfolders are organized, etc)
-  An AI disclosure (it’s acceptable to use AI within reason, and the clearer you are about it, the more people will trust you)
-  The key skills that the project demonstrates

### Public Datasets
- [Kaggle - Misc Datasets](kaggle.com)
- [QIITA - sequencing, mostly 16S microbiome](qiita.ucsd.edu)
- [Built-in R datasets](https://www.datanovia.com/learn/programming/r-foundations/r-built-in-datasets)
- Extract data from published manuscripts (Nature journal is particularly good - look for Data Availability section)
- [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets)

### Vancouver-Centric Bioinformatics Networking
- [BioConnect](https://www.linkedin.com/groups/13518355/) (not strictly bioinformatics, but great networking)
- [Vancouver Bioinformatics User Group](vanbug.org)
- [BiGSAT Research Day](https://www.linkedin.com/in/bigsat-research-day-b8b1852b0/) - UBC Bioinformatics Symposium. Walk among the posters and talk to grad students.
