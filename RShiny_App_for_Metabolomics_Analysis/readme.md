RShiny is an extension of R that lets you give your code a graphical user interface. 
It's the engine behind many online bioinformatic tools, such as [MetaboAnalyst](https://www.metaboanalyst.ca/).

Note that while you can host the app locally for free and can publish it online too, 
the online version only allows a certain amount of usage per month unless you pay for a subscription. 
In other words, it should work fine for a portfolio, but if you're building a real tool for people to 
use, you might need to pay to host it.

Alternatively: get comfortable coding in HTML/javascript and use GitHub pages for free! 
(though it is a real pain to code statistics in these languages...)

**CONSIDER:** 
-  What skills are you trying to demonstrate with your app? 
-  What types of AI use would interfere with showing off these skills? What types would be reasonable/appropriate?

  FYI, there’s no right answer regarding AI - just be honest and realistic when you include it in your portfolio.
