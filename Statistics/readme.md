# Statistics

This folder is a compilation of general statistical techniques.
They are not tied to any one project, and so sample datasets have been used in each case and may differ between scripts.

## AI Disclosure

**AI was used in a limited context to explain key statistical concepts. All AI-generated explanations were independently verified. No AI was used to generate code or this README file.**

## Techniques Covered

See folders for more details.

1.  **Population statistics:** creating a demographics table using clinical study metadata. Includes summary statistics with P values.
2.  **Dimensionality reduction:** finding which foods contribute the most variance to a diet dataset, and whether this is consistent across sexes.
3.  **Correlation analysis:** Parametric and non-parametric correlations between every combination of numeric and categorical variables. Includes univariable and multivariable analyses.
4.  **Longitudinal analysis:** (note to students: these are more advanced techniques) Survival curves and mixed models.
